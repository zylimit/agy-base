## 2. Critical / High 维度规格

每个 critical/high 维度一节；短任务可合并表述，但不能省略决定判定结果的业务依据与条件：

### <维度名>（<critical|high>）

- **业务场景与失效后果**：<谁在什么时段/条件下做什么，发生哪种失效，损失与现行补救是什么>
- **结果定义**：<什么事实/用户结果算正确或完成；与 HTTP 成功、写入、提供方接收等中间事件区分；相关正常/压力/失败/恢复/变更条件>
- **可判定目标与依据**：<数字或明确断言；来源路径/决定；标明已有承诺、已确认新目标或 Agent 候选，不使用无依据的通用 SLA>
- **当前基线**：<实测值、时间、证据与环境；没有测量写未测，不能用 N/A/0 冒充基线>
- **设计手段**：<指向架构中的具体机制/模块，如重试+熔断在 gateway 模块、秘密走 vault>
- **取舍与责任**：<降低哪种损失，增加哪些等待/资源/维护/隐私代价，是否影响其他质量场景；谁负责实现、测量或补救；未知决定影响哪些工作>
- **承载模块与属性映射**：<module-id → attributes 分层，如 payments: security=critical>
- **验证方式**：<verification-matrix check id（须声明对应 attributes）或 manual: 人工核查说明；manual 不代替属性门要求的 fresh PASS>
- **采集实现**：<实际采集位置/事件/结果关联，谁能看到何种结果；目标定义与采集方便不能互相替代>
- **测量条件与判定**：<起止点、代表数据/样本、并发/到达方式、硬件/网络、窗口与分母；观察单位是意图/尝试/记录还是时间片；重试、取消、结果未知、跨窗口与迟到事件怎样计数；无有效分母不能报 100%>
- **盲区与偏差**：<未到达服务的任务、只观察已完成项、采样/分群、低频重要流程等漏计；补足办法与当前声明边界，不以代理指标冒充完整用户结果>
- **反证与实际状态**：<什么观察推翻目标/机制/覆盖声明，最小验证的环境/输入/观察点、实际结果与证据；未运行不预填 PASS>
- **失效模式与降级行为**（Safety/Resilience 相关维度必填）：<故障时系统怎么表现，如何不伤害用户/数据/设备>

<归一化相关目标按规则、契约和变化原因说明是否复用；不为重复实现数归零合并不同职责。升级/迁移相关目标区分中止、可回退、备份恢复与前向修复，保留不可逆数据/外部动作的后果、期间新增数据与恢复验证，不一律承诺 rollback。>

### 显式时延预算（确有预算时选择）

只在当前场景需要预算算术时采用此表，普通 DFX 删除本节即可。先说明实际路径、预算来源/状态、计时起止与已确认执行关系；候选预算保留“候选”标记，不能当用户承诺。将下面骨架移出围栏并填入实际数值后，才对实际文档运行 `dfx check --file PATH`。

```markdown
| Path | BudgetMs | Stage | Mode | Step | Attempts | TimeoutMs | BackoffTotalMs |
|---|---|---|---|---|---|---|---|
| <路径标识> | <该路径预算毫秒> | <阶段标识> | serial或parallel | <步骤标识> | <含首次的总尝试次数> | <单次超时毫秒> | <全部退避之和毫秒> |
```

同一路径的预算保持一致；同阶段的 Mode 一致。每步上界为 `Attempts × TimeoutMs + BackoffTotalMs`，serial 阶段求步骤之和，parallel 阶段取最长步骤，不同阶段串行相加。`Attempts` 是包含首次的正整数，`BackoffTotalMs` 已是所有退避间隔之和，不再乘次数；零次重试即 Attempts=1。此声明不表达任意依赖图或阶段之间并行，不将队列/等待等未写入的成本当已覆盖。

若确有一层调用内部另一重试层的关系，可另外声明：

```markdown
| Chain | Layer | Attempts |
|---|---|---|
| <同一嵌套链标识> | <调用层标识> | <含首次的次数> |
```

同一 Chain 的叶端调用次数上界为各层 Attempts 的乘积，多层放大给出 warning；这不是额外时延，也不自动乘到上面的独立步骤。独立调用不要填成同一链。原业务目标、上述算术和实际测量分别留证：缺预算显式 `checked: 0`/`not-declared` 且非零退出，不是 PASS；预算内也不等于生产 P95、真实超时实现或失败恢复已验证。
